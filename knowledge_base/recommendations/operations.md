# Operational recommendations (EcoPredict)

## Daily
- Check Solarman live: AC power, DC strings, inverter temperature, grid status.
- Compare AC power to clear-sky expectation; large gaps → soiling, shade, or fault.
- Review 3D inverter model telemetry for quick status.

## Weekly
- Inspect for bird droppings, leaves, and dust rings on panels.
- Verify communication uptime (Solarman online).
- Review PR / economics if irradiance data available.

## When power is low
1. Weather: cloud/dust from forecast page.
2. DC: MPPT imbalance or open string.
3. AC: grid faults or curtailment.
4. Visual: Fault Detection on photos.
5. Cleaning: schedule if soiling likely.

## Hybrid optimizer
When both solar and wind forecasts exist, prefer the source with lower relative cost or better reliability for the load; store surplus if battery available.

## Safety
Only qualified personnel open inverter cabinets. Follow lock-out procedures for DC and AC isolation.
