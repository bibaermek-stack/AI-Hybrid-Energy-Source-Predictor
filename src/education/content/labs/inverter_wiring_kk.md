# Зертхана теориясы: инвертор 3D сым тренажері

## Оқу мақсаттары
1. **Solar Inverter Subsystem** CAD құрастырмасында негізгі бөліктерді тану (DC, AC, PE, ажыратқыш, logger).
2. Жиі ақауларды анықтау: кері DC, ашық ажыратқыш, ауысқан L/N, босаң logger.
3. Цифрлық **сым тақтасында** сау топологияны қалпына келтіріп, **Тексеру** арқылы растау.

## Сау топология
| Порт | Дұрыс қосылыс |
|------|----------------|
| DC+ | PV тізбек **+** |
| DC− | PV тізбек **−** |
| PE | Жер шинасы |
| AC L | Желі L |
| AC N | Желі N |
| AC ажыратқыш | Экспорт үшін **ON** |
| Data logger | COM-ға тығыз |

## Қауіпсіздік
Бұл **цифрлық тренажер**. Нақты нысанда: кернеусіздендіру, LOTO, жергілікті электр нормалары. Жүктемеде DC полярлықты ауыстырмаңыз.

## Қалай жұмыс істеу
1. **Ақау сценарийін** таңдаңыз (A–E).
2. **3D модельді** қараңыз (қызыл DC+, көк DC−, күлгін ажыратқыш, қызғылт logger…).
3. **Сым тақтасында** сол порттарды түзетіңіз.
4. **Сымды тексеру** → Дұрыс / Қате (қайтадан көріңіз).
5. Төмендегі теориялық тапсырмаларды шешіңіз.
